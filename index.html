Real-time stroke and fall risk monitoring

SafeRH · Erasmus Mundus · Jul 2023 – Jun 2026

A secure Django platform for a cross-border healthcare project. Connected sensors in an elderly care setting stream readings to the backend, where they are validated, stored and passed to machine learning models that estimate stroke and fall risk as the data arrives.

Python work

  • Django JSON REST endpoints for live sensor ingestion
  • Modular services and data pipelines that prepare readings for model inference
  • Server-side logic that processes patient activity and triggers automated alerts on unusual events
  • Control backend for temperature, light and humidity automation
  • Git-based collaboration within an international engineering team

Retrieval-augmented question answering

Legal Vote · Freelance · May 2023 – May 2024

A generative AI backend for legal case files. Large volumes of unstructured documents are processed into a searchable knowledge base, so users get answers grounded in the source material, with references, instead of unsupported model output.

Python work

  • Ingestion pipeline: parse, chunk and tokenize case files
  • Vector embeddings of each chunk, indexed in Pinecone for semantic search
  • MongoDB Atlas storage of chunks and metadata for traceable retrieval
  • LLM integration that answers only from retrieved passages and cites its sources

Telehealth backend

Quick GP · Freelance · Aug 2024 – Sep 2025

Backend services for an online GP platform. The APIs handle the data flow between patients and healthcare providers for the platform's core clinical requests.

Python work

  • Django REST APIs (JSON) for medical certificate requests, online prescriptions and specialist referrals
  • Server-side support for remote telehealth consultations
  • Request handling between patient and provider sides of the platform
